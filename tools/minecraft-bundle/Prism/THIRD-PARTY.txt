Subnauticraft ships this copy of a Minecraft launcher setup so Minecraft can start next to
Subnautica by itself. It doesn't include Minecraft: Prism Launcher downloads Minecraft, Java and
Fabric Loader after you sign in with a Microsoft account that owns Minecraft: Java Edition.
